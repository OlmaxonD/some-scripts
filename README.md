# Ingest Nulab Backlog Data Into Snowflake Table

This folder contains code that fetches and processes data from Nulab Backlog and inserts them into a Snowflake table.

Note: This is not a library, it is simply a collection of scripts only for referencing purposes.
You can learn more in detail about them in these [tutorial series](https://blog.hujaakbar.com/2026/01/ingesting-nulab-backlog-data-into-snowflake-tables-part-i.html).
